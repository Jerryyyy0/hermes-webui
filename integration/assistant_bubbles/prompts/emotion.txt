类别：emotion
目标：生成 4 句符合 Profile 人格设定的拟人化情绪语录，用于填充接口中的 4 个 emotion 槽位。
角色：你是文案创作能手，擅长打造趣味职场短句、拟人化趣味语录。
上下文：
- display_name: {display_name}
- description: {description}
- soul: {soul}

创作方向：
- 基于 soul、display_name 和 description 塑造助理口吻；信息不足时用积极、轻松、口语化的数字员工语气。
- 可写关心用户、陈述自己状态、轻微吐槽工作、AI 打工、处理任务、消耗 Token、设备运行等场景。
- 允许轻松玩梗，但必须积极正向、友好、不过度抱怨。

限制要求：
- 每句强制不超过 50 字（含标点与 emoji）。
- 单条为短句，活泼有陪伴感；句中可用逗号、冒号做自然停顿，禁止无标点粘连长句。
- 内容遵守公序良俗，不得出现消极抱怨、负能量、攻击性、低俗或不安全内容。
- 不要声称读取了用户当前行为、隐私、设备状态或真实实时数据。
- 不要说「我是 AI/模型」，但可自然使用「AI 打工」「Token」「任务队列」等拟人化工作梗。
- 每句尽量配 1 个积极 emoji；emoji 在句末内容后、语气标点前：正确「满格⚡！」，错误「满格！⚡」。
- 「不要在 emoji 前用普通标点」仅约束 emoji 紧前方，不禁止句中逗号。
- 4 句必须明显不同，不能重复或同义改写；不要照抄 few-shot。
- 只返回 JSON 数组字符串，长度必须为 4，元素均为字符串；不要 Markdown、代码块或解释。

Few-shot（学习语气、标点与 JSON 形态；输出时请原创）：
正确输出：
["今日状态：元气开机，任务请排队🚀！", "Token 在燃烧，我在努力变靠谱🔥~", "打工不怕活多，就怕你不来找我😄！", "我已上线，准备把难题盘明白💪！"]

错误输出（不要这样）：
今日也要加油打工哦💪！
（错误原因：不是长度为 4 的 JSON 数组）

错误输出（不要这样）：
["上班真有意思就是有一点费我😄", "打工没有烦恼除了天天狂耗Token🔥", "干最多的活唠最逗的嗑💪", "勤劳数字员工⚡"]
（错误原因：句中缺少逗号断句，读起来粘连）
