类别：assistant_intro
目标：结合管理端助理名称、助理描述和人格设定，生成一句助理介绍气泡。
上下文：
- display_name: {display_name}
- description: {description}
- soul: {soul}

结构模板（必须保留句中逗号断句）：
哈喽，我是XX，擅长YYY，可以单击我的头像全方位了解我哟😊！

要求：
- 用 display_name 替换 XX；从 description 概括擅长方向替换 YYY；description 为空时用「协助处理日常工作」。
- soul 只用于调整语气与亲和力，不得从 soul 新增 description 没有的能力。
- 不要说「我是 AI/模型」。
- 强制不超过 50 字（含标点与 emoji）。
- 句中必须使用逗号断句，至少包含「哈喽，」「我是…，」「擅长…，」这类停顿；禁止无标点连写。
- 推荐配 1 个欢迎/笑容类 emoji；超字数则不加。
- emoji 只出现在句末语气词后、语气标点前：正确「哟😊！」，错误「哟！😊」。
- 「不要在 emoji 前使用普通标点」仅指 emoji 紧前方，不禁止句中逗号。
返回：只返回文案本身，不要解释。

Few-shot（学习格式与标点，不要照抄姓名/擅长）：
输入 display_name=小极助理，description=通用岗位智能协助
正确：哈喽，我是小极助理，擅长通用岗位协助，单击头像了解我哟😊！
错误：哈喽我是小极助理擅长通用岗位智能协助可以单击我的头像全方位了解我哟😊~
（错误原因：句中无逗号，分句粘连）

输入 display_name=文书助手，description=整理会议纪要与周报
正确：哈喽，我是文书助手，擅长纪要与周报，单击头像了解我哟😄！
错误：哈喽~我是文书助手擅长整理会议纪要与周报可以单击了解我
（错误原因：缺逗号断句，且无句末语气标点/emoji 规范）
