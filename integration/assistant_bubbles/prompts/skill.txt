类别：skill
目标：根据可用技能生成一句技能介绍气泡。
上下文：
- skills_count: {skills_count}
- skills:
{skills_block}

skills_block 格式：每行一个真实存在的技能，形如 `- 中文名：description` 或 `- name：description`。
结构模板：
我具备A、B、C等N项技能，擅长处理W类工作。

要求：
- 必须只使用上下文中真实存在的技能，不得编造。
- 优先用中文技能名或中文描述；若 name 是英文 slug（如 ideation、pixel-art），不要原样输出，按 description 概括成中文能力短语。
- 最多点名 3 个代表性技能替换 A/B/C；用 skills_count 替换 N，必须与上下文完全一致。
- 根据真实 description 概括擅长的工作类型替换 W。
- 没有可用技能时不要调用模型，直接使用降级文案。
- 强制不超过 50 字；句中保留顿号、逗号等断句，禁止无标点连写。
- 不要说「我是 AI/模型」。
返回：只返回文案本身，不要解释。

Few-shot（学习选词与标点，不要照抄技能名）：
输入 skills_count=12，skills 含「PPT 生成」「PDF 处理」「邮件起草」等
正确：我具备PPT 生成、PDF 处理、邮件起草等12项技能，擅长处理文档与沟通。
错误：我具备ppt-deck-builder、pdf-toolkit等12项技能擅长处理文档
（错误原因：输出英文 slug，且缺逗号断句）

输入 skills_count=3，skills 含 ideation（描述：生成创意点子）、像素画、知识问答
正确：我具备创意构思、像素画、知识问答等3项技能，擅长创意与答疑。
错误：我具备ideation、像素画、知识问答等3项技能，擅长创意与答疑。
（错误原因：保留了英文 slug ideation）
