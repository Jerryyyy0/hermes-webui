- **状态：** 已实施
- **创建日期：** 2026-08-21

## 1. 目标与已采纳决策

成功工具在当前 turn 明确生成或修改的文件，即使位于 `session.workspace` 和默认 workspace 之外，
也可以成为 file Artifact。文件继续留在原位置；Manifest 保留外部文件的绝对路径，并复用既有
`GET /api/integration/workspace/file?path=...` 做只读预览。

该能力采用“受控活引用”，而不是内容快照：系统不移动、复制、软链接、哈希或保存文件内容。源文件
内容变更或同名普通文件替换后，预览当前安全版本；文件消失、不再是普通文件或后来违反策略时，
Manifest 投影为 `expired`。

跨目录预览不是通用本机文件读取能力。绝对路径必须有精确持久化的 Artifact row，并在每次预览时
再次通过安全打开和路径策略。附件和 `HERMES_HOME/memories/` 同样遵循此规则：上传或文件存在本身
不创建 Artifact，也不授予预览权限。

`MEDIA:` 仍是独立的证据和派生通道；已登记的绝对 media Artifact 可以复用只读 preview URL，
但这不改变其生成条件、去重规则或来源语义。

## 2. 兼容性约束

以下公开契约保持不变：

- `GET /api/session/manifest`；
- SSE `manifest_delta`；
- `GET /api/integration/workspace/file?path=...` 的 URL、method、query 参数与响应字段；
- SQLite 表结构、`workspace_root` 的 store identity 与既有唯一键。

不新增虚拟路径、`storage_kind`、文件身份或 SHA-256 字段。workspace 内 Artifact 保持原有相对路径
表示与 preview 行为；外部 Artifact 使用原始绝对路径表示。

## 3. 非目标

- 不把 Manifest 变成 workspace、附件目录或本机磁盘的文件索引；
- 不让目录枚举、读取工具、搜索命中、terminal stdout 或用户上传自动产生 Artifact；
- 不允许凭任意绝对路径预览、编辑、保存、删除、重命名、上传或 Git mutation；
- 不在 Manifest GET、会话打开或普通 turn 结算时自动 repair/backfill 历史记录；
- 不改变普通 workspace 文件的编辑、下载或相对路径语义。

完整的候选来源、最后 assistant 路径边界、受保护路径与附件/memory 例外，见
[Session Manifest Artifacts 实现](../architecture/session-manifest-artifacts.md)。

## 4. 代码归属与迁移结果

Fork 专有的 Manifest 实现在 `integration/session_manifest/`：

```text
integration/session_manifest/
  manifest.py
  store.py
  repair.py
  external_references/
    policy.py
    references.py
    preview.py
```

`external_references/` 承担外部直接引用的策略、安全打开、精确 record 查询与 preview 授权。
`integration/workspace/handlers.py` 只保留既有 URL 的路由分发和薄调用；上游流式/Gateway 接缝只保留
必要 import 与 turn settlement 调用。

原 `api/session_manifest.py`、`api/session_manifest_store.py` 与 `api/session_manifest_repair.py` 已整体迁入
上述 package，调用方直接使用新入口，不保留兼容 shim。迁移不改变数据库路径、表、行数据或公开 API。

Integration 接缝和路由登记见 [integration README](../../integration/README.md) 与
[Hermes 外部集成说明](../hermes-external-integration.md)。

## 5. 验收与后续变更

实现验收以“Session Manifest Artifacts 实现”的测试章节为准，覆盖正常/Gateway/error/cancel 结算、
lineage/profile/root 隔离、外部路径授权、附件/memory、绝对 media、expired 与现有 preview URL 回归。

后续若改变 Artifact 资格、安全策略、持久化或 preview 授权，必须先更新
[Session Manifest Artifacts 实现](../architecture/session-manifest-artifacts.md)；改变请求或响应契约时，
还必须同步更新 [Session Manifest HTTP/SSE 契约](../api/session-manifest-api.md)。本文只在目标、取舍、
非目标或迁移边界改变时更新。
